Cryptographic Intake Protocol
Chunked Stream Processing

Evidence files are read in buffered 8,192-byte blocks. This ensures efficient, low-memory cryptographic calculation for files of any size.

Immutable SHA-256 Fingerprint

A 256-bit cryptographic digest is generated instantly upon upload and permanently stored with the evidence record in MongoDB.

Chain of Custody Initiation

An initial custody record is written to the audit log documenting the uploading officer, exact timestamp, and original file attributes.

Tamper Testing Demo

To demonstrate tamper detection during viva presentation:

  1. Upload a sample text or image file.
  2. Run verification on the evidence page → Evidence Intact.
  3. Modify even a single character in evidence_files/.
  4. Verify again → Immediate Tamper Alert with hash mismatch.
